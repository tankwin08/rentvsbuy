# Rent vs Buy Calculator

A simple, interactive web-based calculator to help you decide whether renting or buying a home makes more financial sense based on your specific circumstances.

## Features

- **Comprehensive Analysis**: Input your financial details including home price, down payment, interest rates, rental costs, and more
- **Visual Results**: Clear breakdown showing costs over time for both renting and buying scenarios
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Real-time Calculations**: Instant updates as you adjust parameters

## Demo

Access the live calculator at: [https://tankwin08.github.io/rentvsbuy/](https://tankwin08.github.io/rentvsbuy/)

## Usage

1. Open the calculator in your web browser
2. Enter your financial details:
   - Home purchase price
   - Down payment amount
   - Mortgage interest rate
   - Loan term
   - Current monthly rent
   - Expected rent increases
   - Property taxes and insurance
   - Maintenance costs
   - Investment returns
3. Adjust the time horizon for analysis
4. View the comparative results to make an informed decision

## Local Development

To run the calculator locally:

1. Clone this repository
2. Open `index.html` in your web browser
3. No additional setup required - it's a pure HTML/CSS/JavaScript application

## Deployment

This project is deployed using GitHub Pages. To deploy your own version:

1. Fork this repository
2. Enable GitHub Pages in your repository settings
3. Select the main branch as the source
4. Your calculator will be available at `https://yourusername.github.io/rentvsbuy/`
